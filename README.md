# Systems Programming

A practical exploration of systems programming in C and Rust, undertaken by an experienced full-stack software engineer expanding into native software development and Linux systems engineering.

## Objectives

- Understand computer architecture and memory management.
- Develop proficiency in C and Rust.
- Understand Linux system calls and operating system internals.
- Implement low-level networking and concurrent applications.
- Explore native integration with Node.js and TypeScript.
- Develop practical, well-tested systems software.

## Development Environment

- Host: Ubuntu Linux
- Guest: Debian 13
- Virtualization: QEMU/KVM
- Languages: C, Rust and TypeScript
- Compilers: GCC and Clang
- Debugging: GDB, Valgrind, strace
- Editor: VSCodium via SSH
